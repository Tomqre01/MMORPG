# King of Origin — Credits

**King of Origin** is an original MMO-RPG prototype. The capital city of its world is **Aurelion**.

## Team
- Game direction and production: Tom (Tomqre01)
- Engineering, technical art, game and UI design: built together with Claude (Anthropic)

## Engine and packages
- Unity 6.3 LTS (6000.3.26f1) with the Universal Render Pipeline
- Unity Input System, uGUI, AI Navigation, Timeline (Unity packages)
- Nakama by Heroic Labs: online server and its Unity client

## Art and audio
- Player heroes, monsters, UI skin and effects: made in this project by script
  (Blender 5.2 for the 3D models, Unity code for the UI), see `Tools/Blender` and `Assets/Scripts/UISkin.cs`.
- Third-party asset packs in the project keep their own licences:
  RPG Monster DUO PBR Polyart and DogKnight (Unity Asset Store), used only as placeholders.

## Game data
- Map layout, monster names, levels and gear names were adapted from configuration data the project
  owner supplied. No game client art, models or audio from other games are included.
