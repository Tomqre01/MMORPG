# ออนไลน์ ขั้นที่ 1: เซิร์ฟเวอร์ ล็อกอิน และเซฟบนเซิร์ฟเวอร์

เซิร์ฟเวอร์เกมใช้ [Nakama](https://heroiclabs.com/nakama/) (ฟรี โอเพนซอร์ส) รันบนคอมของเราผ่าน Docker
มีระบบล็อกอิน เก็บเซฟ แชท และเห็นผู้เล่นอื่นให้พร้อม เราจะเปิดใช้ทีละอย่าง

ขั้นนี้ทำได้:
- เปิดเกมแล้วเจอหน้า **Login** ใส่ที่อยู่เซิร์ฟเวอร์แล้วกด Login (หรือกด **Play Offline** เล่นแบบเดิม)
- ล็อกอินครั้งแรก เซฟในเครื่องจะถูกอัปขึ้นเซิร์ฟเวอร์ ครั้งต่อไปโหลดเซฟจากเซิร์ฟเวอร์
- ระหว่างเล่น เซฟจะส่งขึ้นเซิร์ฟเวอร์ทุกครั้งที่บันทึก (ประมาณทุก 5 วินาทีเมื่อมีอะไรเปลี่ยน)
- บัญชีผูกกับเครื่อง (Unity Editor บนคอม กับ MuMu นับเป็นคนละบัญชี)

## 1. ติดตั้ง Docker Desktop (ครั้งเดียว)
1. โหลดจาก https://www.docker.com/products/docker-desktop/ เลือก **Windows**
2. ติดตั้งตามค่าเริ่มต้น (ใช้ WSL 2) ถ้าให้รีสตาร์ทคอมก็รีสตาร์ท
3. เปิด Docker Desktop รอจนมุมล่างซ้ายขึ้น **Engine running** (ข้ามการสมัครสมาชิกได้)

## 2. เปิดเซิร์ฟเวอร์
1. เปิดโฟลเดอร์ `server` ในโปรเจกต์ (เช่น `D:\MMORPG\server`)
2. คลิกช่องที่อยู่ไฟล์ด้านบนของหน้าต่าง พิมพ์ `cmd` แล้วกด Enter
3. พิมพ์ `docker compose up -d` แล้วกด Enter รอบแรกจะโหลดนานหน่อย
4. เปิดเบราว์เซอร์ไปที่ http://127.0.0.1:7351 ถ้าเห็นหน้าล็อกอิน Nakama Console แปลว่าเซิร์ฟเวอร์ทำงานแล้ว
   (ชื่อ `admin` รหัส `password`) ดูผู้เล่นได้ที่เมนู **Accounts** และดูเซฟได้ที่ **Storage**

ปิดเซิร์ฟเวอร์: `docker compose down` ในโฟลเดอร์เดิม (เซฟยังอยู่ ไม่หาย)

## 3. ล็อกอินจากเกม
- **ใน Unity Editor**: กด Play ช่อง Server เป็น `127.0.0.1` อยู่แล้ว กด **Login**
- **บน MuMu**: ใช้ `127.0.0.1` ได้เลย เพราะตอน Unity ต่อ MuMu (Tools > Android > Connect MuMu Emulator
  หรือเปิดโปรเจกต์ตอนเป้าหมายเป็น Android) จะสั่ง `adb reverse tcp:7350` ให้ 127.0.0.1 ในอีมูเลเตอร์วิ่งมาที่เซิร์ฟเวอร์บนคอม
  ถ้าปิดเปิด MuMu ใหม่ ให้กดเมนูนี้อีกครั้งก่อนล็อกอิน
- **บนมือถือจริง**: ต้องใส่ IP ของคอม
  1. ที่คอม เปิด cmd พิมพ์ `ipconfig` ดูบรรทัด **IPv4 Address** เช่น `192.168.1.35`
  2. ในเกมพิมพ์ IP นั้นในช่อง Server แล้วกด Login (เกมจำไว้ให้ครั้งต่อไป)
  3. มือถือจริงต้องต่อ Wi-Fi วงเดียวกับคอม
  4. ถ้า Windows ถามเรื่อง Firewall ของ Docker ให้กด **Allow**

ถ้าขึ้น `Can't connect` ให้เช็กว่า Docker Desktop เปิดอยู่ และหน้า http://127.0.0.1:7351 เปิดได้

## เห็นผู้เล่นคนอื่น (ขั้นที่ 2)
ทุกคนที่ล็อกอินจะเข้าห้องเดียวกันชื่อ `world` แล้วส่งตำแหน่งตัวเองหากันทุก 0.1 วินาที
ผู้เล่นคนอื่นจะเห็นเป็นตัวละครตามอาชีพ มีปีกตามเลเวลปีก และมีป้ายชื่อสีฟ้าบนหัว (ยังเป็นชื่อสุ่มจากเซิร์ฟเวอร์)

ทดสอบคนเดียว 2 จอ:
1. เปิดเซิร์ฟเวอร์ ใน Unity กด Tools > Android > Connect MuMu Emulator แล้วเปิดเกมใน MuMu ล็อกอินด้วย `127.0.0.1`
2. กด Play ใน Unity แล้วล็อกอินด้วย `127.0.0.1`
3. เดินไปที่เดียวกัน จะเห็นอีกตัวเดินตาม ตีมอน และตาย/เกิดใหม่ตามจริง

ถ้าเน็ตหลุด เกมจะลองต่อใหม่เองทุก 5 วินาที

## หมายเหตุ
- รหัส `defaultkey`, `localdb`, `admin/password` ใช้แค่ตอนพัฒนาบนคอมตัวเอง ก่อนเปิดให้คนอื่นเล่นต้องเปลี่ยนทั้งหมด
- โค้ดฝั่งเกมอยู่ที่ `Assets/Scripts/Online.cs` ตัว SDK ของ Nakama อยู่ที่ `Assets/Plugins/Nakama` (Apache 2.0)
- เกมบน Android ต่อเซิร์ฟเวอร์แบบ http ได้เพราะ `Assets/Editor/OnlineSettings.cs` เปิด Allow downloads over HTTP ให้
